# 🧮 Node.js Calculator App using ESM

This is a simple command-line calculator application built with **Node.js** that demonstrates the use of:

- ✅ Built-in Node.js modules
- 📦 Third-party npm modules
- 🛠️ Custom user-defined modules

---

## 📚 Features

- Perform basic arithmetic operations: **Addition, Subtraction, Multiplication, Division**
- Uses **prompt-sync** for the user input (third-party)
- Uses **chalk** for the colorful terminal output (third-party)
- Custom calculator logic in separate module (`calculator.js`)
- Input validation and divide-by-zero handling
